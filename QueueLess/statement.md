# Project Statement

## Project Title

QueueLess: Virtual Campus Queue Management System

## Problem Statement

Students can spend unnecessary time physically waiting at campus services such as canteens, administrative offices, medical desks and help desks. QueueLess provides a local virtual token and queue-management system so that a student can join a queue, check their position and estimate the waiting time without continuously standing in a physical line.

## Scope

The project covers student registration, token generation, multiple service queues, priority handling, queue-position calculation, estimated waiting time, staff queue operations, token cancellation and completion, and local CSV persistence.

The current implementation is a desktop Java Swing application. It is intentionally local rather than a networked multi-user deployment.

## Target Users

- Students
- Campus service staff
- Administrators during demonstrations

## High-Level Features

1. Student registration for a queue
2. Multiple campus service queues
3. Priority assistance
4. Queue position and ETA
5. Call-next operation
6. Serving and completion status
7. Token cancellation
8. Local CSV storage
9. Input validation
